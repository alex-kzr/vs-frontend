# Vacancy Search Frontend

React web client for Vacancy Search. This repository is prepared for application implementation; no application code or package manifest exists yet.

## Ownership

Frontend owns source, dependency locks and frontend tests here. The umbrella repository owns the shared API contract and architecture: https://github.com/alex-kzr/vacancy-search/tree/main/docs

Intended submodule path: `repos/frontend`. Implement against the umbrella API contract. TypeScript and Vite are documented recommendations; verify supported versions before adoption.
